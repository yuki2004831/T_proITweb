## タイトル 北海道とタイの観光スポット（仮）

### チーム１
- 北海道の観光スポットと北海道のホームページの作成

    #### 担当ページ

    - destinaton.html（岡野）

    - hokkaido_activity.html（岡野）

    - hokkaido_main.html（坂本）

    - hokkaido_mesi.html（岡野）

    - hokkaido_zekkei.html（寺川）

    - kihon.html（寺川）

    #### 追加されているページ内容

    - hokkaido_main.html：北海道ページのトップページ。基本情報ページと目的地ページへのリンクを表示。

    - kihon.html：北海道の基本情報をまとめたページ。

    - destinaton.html：北海道の観光ページへ移動するためのページ。

    - hokkaido_mesi.html：いくら丼、ザンギ、ジンギスカン、寿司、豚丼など北海道の食べ物を紹介するページ。

    - hokkaido_zekkei.html：四季彩の丘、旭山動物園、小樽運河、白金青い池、五稜郭など北海道の観光スポットを紹介するページ。

    - hokkaido_activity.html：北海道の春・夏・秋・冬ごとのアクティビティを紹介するページ。
